THE HUMAN CAPABILITY

The mind keeps thinking after attention leaves

Low-level processing on unfinished work that keeps running while attention is elsewhere, then resurfaces as insight.

Wallas's four stages (1926). Incubation is the stage no current AI system performs.

LIMITS OF CURRENT AI

When the call ends, the thought ends

Invocation-bound: in today's AI, nothing computes unless something is called.
Compute = attention Thought ends at output Frozen between calls Memory never works No learning in use
Closest today: sleep-time compute (Lin et al., 2025) cuts test-time compute ~5×, yet it is a batch job, not a mind that keeps working.
